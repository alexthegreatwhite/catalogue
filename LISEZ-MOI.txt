VOTRE DEMANDE

CE QUE FAIT LA V9 (fonction maybeFollowSite, au lancement de la page)
  Copie locale ouverte AVEC internet :
    1. les DONNÉES sont d'abord rafraîchies comme d'habitude (adoption
       automatique de la base GitHub — votre repli hors ligne est à jour) ;
    2. l'app compare son build au build du dépôt (sonde de 8 s sur
       raw.githubusercontent) ;
    3. build différent (une maj existe) → toast « Mise à jour disponible
       (…) : bascule sur le site en ligne… » puis BASCULE AUTOMATIQUE sur
       https://alexthegreatwhite.github.io/catalogue/ — vous vous retrouvez
       sur la dernière version sans aucune manipulation ;
    4. build identique → vous restez en local (photos manquantes rechargées
       depuis GitHub tant qu'internet est là — patch v7).
  Copie locale ouverte SANS internet :
    → démarrage local normal, en silence, avec les données de la dernière
      connexion. Rien n'est tenté (sonde ignorée si navigator.onLine=false).
  Sur le site Pages (smartphone, ou PC après bascule) :
    → la fonction ne fait jamais rien (détection du hostname — aucune
      boucle de redirection possible).

  Pourquoi une bascule et pas une réécriture du fichier ? Un navigateur ne
  peut PAS modifier les fichiers du disque (sandbox de sécurité) — c'est
  impossible pour n'importe quel site web. La bascule vers le site en ligne
  est LA mise à jour automatique : connecté = toujours la dernière version.

À FAIRE UNE FOIS (la dernière manipulation manuelle)
  1. PUBLIER : repo → Add file → Upload files → glisser index.html ET
     README.md de CE dossier → commit sur main.
  2. PC : remplacer l'index.html du dossier local par celui-ci (pour que la
     copie HORS LIGNE bénéficie aussi de tout : recherche œ, codes-barres
     plein écran, adoption auto, photos fiabilisées, bascule auto).
     — Si vous ne le faites pas, ce n'est pas bloquant : au prochain
       lancement connecté, la vieille copie locale détectera la v9 sur le
       dépôt et basculera sur le site automatiquement.
  3. Vérifier : lancer la copie locale, PC connecté → toast « Mise à jour
     disponible » → le site s'ouvre. Console (F12) sur le site :
     « [Catalogue Pro] build 2026-10-22-maj-auto-v9 ».

ENSUITE, AU QUOTIDIEN
  - PC connecté + lancement → vous êtes toujours sur la dernière version
    (site) ; les données locales sont rafraîchies au passage ;
  - PC déconnecté + lancement → copie locale avec les données de la
    dernière connexion ;
  - Pour que le repli HORS LIGNE ait aussi le dernier CODE et les dernières
    PHOTOS : re-télécharger le ZIP de temps en temps (Code → Download ZIP)
    — optionnel, seulement pour améliorer le confort hors ligne.
